# LessonSpec compatibility

`LessonSpec` version `1.7` is the current immutable, strict contract. Consumers must parse unknown JSON with `parseLessonSpec` before use.

`parseLessonSpec` explicitly migrates compatible `1.0` through `1.6` documents to `1.7`. Version `1.2` scalar IPO values are transformed losslessly into one-item input and output collections. Version `1.3` comparison labels become left and right structured subjects without losing text. Version `1.4` cause/effect labels become ordered node IDs and explicit directed connections without losing text. Version `1.5` labelled-diagram descriptions become the approved shapes-only fallback and bounded semantic anchors. Version `1.6` analogies require a teacher-led migration because their former free-text mappings cannot be converted safely into explicit concept-to-familiar-system pairs. A legacy definition, process, cause/effect graph, analogy, or diagram that exceeds current density limits is rejected for a teacher-led migration; content is never silently truncated. Unknown versions are rejected. Additive or breaking future changes require a new schema version, migration fixtures, and explicit compatibility handling; no consumer may infer compatibility from an unknown version.
