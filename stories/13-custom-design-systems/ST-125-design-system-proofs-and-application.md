# ST-125 - Moving design proofs, refinement and explicit project application

Implement step 4 of docs/bring-your-own-design-system.md under ADR-017 after
ST-124 is Done. Provide short moving proofs using opening/explanation/diagram
or chart content; use the current lesson when available or labelled sample
content. Meter paid proof work and support conversational, reviewable refinement.
Explicit application pins the published system version and resolved manifest
without rewriting prior videos. Archive prevents new selection but preserves
saved versions and bytes. Integrate reuse across the owner's projects.

Acceptance: actual MP4 review at desktop/phone sizes; philosophy is recognisable;
composition/motion differ beyond colour; locks, glyphs, readable holds, safe
areas and captions validate; stale edits/concurrent apply fail safely; histories
remain reproducible; authorization, idempotency, failure and UI checks pass.

Out of scope: organisation sharing, live integrations, demonstration mode,
arbitrary generated animation code.
